# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
Its short version: be kind, assume good faith, and keep criticism about the
work rather than the person. Harassment, insults and publishing anyone's
private information are not welcome here, in issues, pull requests or
anywhere else this project lives.

That last one matters more than usual in this repository. The live site holds
real residents' and real businesses' details. Never paste a phone number,
email, address or account detail from it into an issue, a test fixture or a
screenshot — use invented ones, like the ones in `supabase/seed.sql`.

## Reporting

Write to **railkarsoham@gmail.com**. Reports are read by the maintainer only
and kept private. If the problem is with the maintainer, say so in the report
and it will be handled with that in mind.
